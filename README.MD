# TodoList Mini Project

A simple TodoList backend application built with **TypeScript**, **Express.js**, and **MySQL**.  
This project is for practice and learning purposes.

---

## Features


- Create, Read, Update, Delete (CRUD) todos  
- Route protection with middleware  
- Input validation and error handling  

---

## Tech Stack

- **Backend:** Node.js, Express.js, TypeScript  
- **Database:** MySQL  
- **ORM / Query:** mysql2 / raw queries  
- **Tools:** ts-node-dev, nodemon  

---

## Prerequisites

- Node.js >= 18  
- MySQL >= 8  
- npm / yarn
